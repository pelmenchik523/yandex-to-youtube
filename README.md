# YouTube → Яндекс Станция Lite 2

Мост на этом компьютере: ищет трек на YouTube, скачивает MP3, отдаёт его по
локальной сети на колонку и управляет воспроизведением через SSH. Сверху —
веб-пульт и webhook для приватного навыка Алисы.

## Быстрый старт

```bash
cd ~/ytstation
./start.sh
```

Скрипт поднимает мост и SSH-туннель (если они ещё не запущены) и печатает
адреса. Веб-пульт:

```
http://192.168.1.167:8888/
```

Остановить всё:

```bash
./stop.sh
```

Полезные файлы:

| Файл | Что внутри |
|---|---|
| `bridge.py` | мост, HTTP-сервер, API, webhook Алисы |
| `web/index.html` | веб-пульт (один файл, без внешних зависимостей) |
| `settings.json` | настройки YouTube (создаётся из веб-пульта) |
| `playlists.json` | сохранённые плейлисты (создаётся из веб-пульта) |
| `cookies.txt` | необязательный cookies-файл в формате Netscape |
| `bridge.log` | лог моста |
| `localhostrun.log` | лог туннеля и актуальный публичный URL |
| `start.sh` / `stop.sh` | запуск/остановка |

## Веб-пульт

- **Что играет** — обложка, название, прогресс, пауза/продолжить, следующий,
  предыдущий, стоп, громкость.
- **Поиск** — введите название или исполнителя и нажмите «Включить».
- **Очередь** — топ-5 результатов поиска; клик по строке включает трек.
- **YouTube: вход и плейлисты** — cookies из браузера на этом компьютере,
  проверка входа, плейлист по ссылке/ID, быстрые кнопки «Мне понравилось»
  (`LL`) и «Смотреть позже» (`WL`), сохранённые плейлисты.
- **Подсветка** — цвет верхнего кольца, яркость, готовые цвета, режимы
  «Статика», «Дыхание», «Авто (Алиса)», «Выкл».
- **Питание** — усилитель (мгновенный mute/unmute), перезагрузка и полное
  выключение колонки.
- **Навык Алисы** — актуальный webhook и кнопка копирования.

Веб-пульт доступен только в локальной сети. Публичный туннель отдаёт наружу
только `/alice` и `/health`; страница и API через него не доступны.

## Вход в YouTube и плейлисты

Мост не хранит пароль YouTube. Он использует cookies браузера на этом
компьютере:

1. Войдите в YouTube в Firefox (по умолчанию) или другом браузере.
2. В веб-пульте, в карточке **«YouTube: вход и плейлисты»**, укажите браузер
   (например, `firefox`) и нажмите **«Проверить вход»**.
3. Если Firefox использует отдельный профиль, можно указать его так:
   `firefox:default-release` (или `firefox:путь-к-профилю`).
4. Вместо браузера можно указать путь к экспортированному `cookies.txt`
   в формате Netscape. Если файл указан, он имеет приоритет.
5. Если YouTube не открывается с этого компьютера напрямую (TLS-таймауты,
   блокировка провайдера), укажите **«Прокси для YouTube»** — например,
   `socks5://127.0.0.1:1080` или `http://127.0.0.1:8080`. Этот прокси
   используется только для `yt-dlp`.

После успешного входа:

- **«Мне понравилось (LL)»** — плейлист лайков;
- **«Смотреть позже (WL)»** — отложенные видео;
- вставьте ссылку вида
  `https://www.youtube.com/playlist?list=...` (или сырой ID) и нажмите
  **«Играть»**;
- **«Сохранить»** добавляет текущий или указанный плейлист в список на этом
  компьютере (`playlists.json`).

Голосом: «включи любимые», «включи смотреть позже», «включи плейлист <название
из сохранённых>».

Если проверка входа не проходит, обновите страницу YouTube в браузере,
убедитесь, что вы вошли в аккаунт, и повторите. Для приватных плейлистов
cookies обязательны. `settings.json`, `playlists.json` и `cookies.txt` —
локальные файлы, их не нужно коммитить.

## Навык Алисы

1. Откройте <https://dialogs.yandex.ru/developer>.
2. Создайте навык → «Навык в Яндекс Диалогах» → приватный.
3. Название/активация: **Ютуб** (или любое своё; фраза будет
   «Алиса, попроси Ютуб …»).
4. Backend: **Webhook URL**. Скопируйте его из карточки «Навык Алисы» в
   веб-пульте — там всегда актуальный адрес. Формат:
   `https://<домен>.lhr.life/alice`.
5. Опубликуйте навык (приватный, без общей модерации).
6. Проверьте во вкладке «Тестирование»:

```
включи Rick Astley
включи любимые
включи смотреть позже
что играет
дальше
назад
пауза
продолжи
стоп
громче
тише
громкость 5
```

На колонке: **«Алиса, попроси Ютуб включить …»**.

### Важно про туннель

`localhost.run` на бесплатном тарифе периодически меняет домен. Веб-пульт
всегда показывает актуальный URL (читает `localhostrun.log`). Если навык
перестал отвечать:

1. Откройте веб-пульт.
2. Скопируйте новый webhook из карточки «Навык Алисы».
3. Замените URL в настройках навыка в Яндекс Диалогах.

Для постоянного URL нужен платный custom domain у `localhost.run`, свой VPS
или другой стабильный HTTPS-релей. Бесплатный `cloudflared` на этой сети не
работает: наружу закрыт порт 7844.

## Питание и подсветка: детали

- **Усилитель** — это коммутация каналов FS2105 (`amixer cset numid=3/4`).
  Мгновенно выключает/включает звук, не трогая питание платы.
- **Перезагрузить** — `/sbin/reboot`.
- **Выключить** — `/sbin/poweroff`. Включить обратно удалённо нельзя:
  у Lite 2 нет Wake-on-LAN. Нужна кнопка на корпусе или умная розетка.
- **Подсветка** — sysfs `/sys/class/leds/plum:{red,green,blue}:ring{1,2,3}`.
  «Авто» возвращает кольцо Алисе (trigger `led_ring_fb`). «Статика» и
  «Дыхание» забирают кольцо у Алисы до нажатия «Авто».
- После перезагрузки колонки подсветка возвращается в авторежим.

## Если что-то не работает

```bash
cd ~/ytstation
tail -50 bridge.log
tail -20 localhostrun.log
./stop.sh && ./start.sh
```

Проверка колонки:

```bash
ssh -p 2222 root@192.168.1.206
```

Если нативная Яндекс.Музыка на колонке молчит, а через веб-пульт звук есть,
проверьте на колонке:

```bash
grep -i proxy /system/vendor/quasar/launch.json
cat /proc/sys/net/ipv6/conf/wlan0/disable_ipv6
```

В `launch.json` не должно быть мёртвого `http_proxy`/`https_proxy`
(например, `127.0.0.1:10808`, если на этом порту никто не слушает). Если у
Wi-Fi нет рабочего глобального IPv6, оставьте `disable_ipv6=1`: иначе
`souphttpsrc` может выбрать IPv6-адрес стрим-хоста и не скачать поток.
Наш фикс — `/etc/sysctl.d/99-ytstation-ipv4.conf`.

Проверка моста:

```bash
curl http://127.0.0.1:8888/api/status
curl http://127.0.0.1:8889/health
```

Автозапуск после включения компьютера (по желанию):

```bash
crontab -e
# добавить строку:
@reboot /home/pelmenchik523/ytstation/start.sh >/dev/null 2>&1
```
